คู่มือการติดตั้ง Supabase และนำระบบขึ้น Cloud (Vercel)

ระบบประเมินประสิทธิภาพการจัดการเรียนการสอน • วิทยาลัยเกษตรและเทคโนโลยีมหาสารคาม

⭐ แนะนำขั้นตอนแบบ Best Practice
1 รหัสผ่านได้ทำการ Hash หรือไม่?

✅ เข้ารหัสด้วย SHA-256 เรียบร้อย 100%: ทั้งบัญชีเริ่มต้นในระบบ (admin, director), บัญชีที่สร้างใหม่ และบัญชีที่แก้ไขเปลี่ยนรหัสผ่าน จะถูกแปลงเป็น Hex String ความยาว 64 ตัวอักษรผ่าน Web Crypto API ก่อนจัดเก็บ ไม่มีการเก็บเป็นข้อความธรรมดา

2 ข้อมูลตอนนี้บันทึกลงในเครื่องใช่ไหม?

✅ ใช่ครับ อยู่ใน Browser LocalStorage ของท่าน: ระบบมีระบบสลับอัตโนมัติ (Hybrid Fallback) หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะบันทึกข้อมูลทั้งหมดลงในเครื่องของท่านอัตโนมัติ ทำให้ทดลองใช้งานหน้าเว็บได้ทันทีโดยไม่ error

3 มีโค้ด SQL สำหรับสร้างฐานข้อมูลไหม?

✅ มีไฟล์ SQL เตรียมไว้ให้พร้อม 100%: อยู่ที่ไฟล์ supabase_schema.sql มีทั้งคำสั่งสร้าง 8 ตาราง, ตั้งค่าสิทธิ์ RLS สำหรับเด็กนักเรียน และข้อมูลเริ่มต้น (Seed Data) รันคลิกเดียวจบ

4 ควรทำขั้นตอนไหนก่อน-หลัง?

⭐ ลำดับที่ดีที่สุดและปลอดภัยที่สุด:
สร้าง Supabase ➔ ทดสอบบน Localhost ให้ชัวร์ 100% ➔ อัปขึ้น Git ➔ Deploy ขึ้น Vercel (เพราะจะมั่นใจได้ว่าเว็บที่ขึ้น Cloud จะมีฐานข้อมูลพร้อมใช้งานทันที)

Step-by-Step Deployment Roadmap

ขั้นตอนการย้ายฐานข้อมูลและนำระบบขึ้น Cloud

ปฏิบัติตาม 6 ขั้นตอนนี้ ระบบจะพร้อมใช้งานบนอินเทอร์เน็ตจริง มี URL ให้นักเรียนและผู้บริหารเข้าใช้งานได้ตลอด 24 ชั่วโมง

1

สร้างโปรเจกต์ Supabase

สมัครและสร้างโปรเจกต์ใหม่ฟรี เลือกภูมิภาคสิงคโปร์ (Singapore)

2

รันสคริปต์ SQL Schema

ก๊อปปี้ไฟล์ supabase_schema.sql ไปวางใน SQL Editor แล้วกด Run

3

เชื่อมต่อด้วยไฟล์ .env

นำ URL และ anon key มาใส่ในไฟล์ .env ในเครื่องคอมพิวเตอร์

4

ทดสอบในเครื่องให้ชัวร์

ลองตอบแบบประเมินและดูข้อมูลจริงในตาราง Supabase Table Editor

5

Push โค้ดขึ้น GitHub

สร้าง Repository ใน GitHub แล้วนำโค้ดขึ้นระบบเวอร์ชันคอนโทรล

6

Deploy ผ่าน Vercel (Online)

เชื่อมต่อ GitHub กับ Vercel ใส่ Env Variables แล้วกด Deploy เสร็จสิ้น!

1

ขั้นตอนที่ 1: สร้างโปรเจกต์ Supabase (ฐานข้อมูล Cloud ฟรี)

สมัครใช้งานและเตรียมพื้นที่จัดเก็บข้อมูล

💡 สามารถใช้อีเมลใหม่ที่ไม่มี Git สมัคร Supabase ได้ 100%

• ไม่ต้องมี GitHub: Supabase สามารถกดสมัครผ่าน Email + Password ทั่วไป หรือกด Continue with Google (Gmail) ได้ทันที
• แก้ปัญหาโควต้าฟรีเต็ม (2 โปรเจกต์): การใช้อีเมลใหม่จะทำให้ได้โควต้าสร้างโปรเจกต์ฟรีใหม่อีก 2 โปรเจกต์ทันที
• คนละอีเมลไม่มีผลกระทบใดๆ: ระบบเว็บและ Vercel เชื่อมต่อ Supabase ผ่าน URL และ Key เท่านั้น ไม่ได้สนใจว่าใครเป็นเจ้าของอีเมล จึงสามารถแยก Git ไว้เมลเดิม และ Supabase ไว้อีเมลใหม่ได้อย่างสมบูรณ์แบบ

  1. เปิดเว็บไซต์ https://supabase.com แล้วกด Sign in หรือ Start your project
    ➔ หากบัญชีเดิมเต็ม ให้เปิด หน้าต่างไม่ระบุตัวตน (Incognito) หรือล็อกเอาต์ แล้วกด Sign Up ด้วยอีเมลใหม่ หรือกดล็อกอินด้วย Google
  2. กดปุ่ม "New project"
  3. กรอกรายละเอียดโปรเจกต์:
    • Name: ตั้งชื่อ เช่น eval-msat หรือ msat-evaluation
    • Database Password: ตั้งรหัสผ่านฐานข้อมูล (กรุณาจดบันทึกไว้)
    • Region: แนะนำเลือก Singapore (ap-southeast-1) เพราะใกล้ประเทศไทยที่สุด ตอบสนองเร็วที่สุด
  4. กดปุ่ม "Create new project" และรอระบบเตรียมฐานข้อมูลประมาณ 1–2 นาที
2

ขั้นตอนที่ 2: รันสคริปต์ SQL สร้างโครงสร้างตาราง (Schema)

สร้างตารางทั้ง 8 ตาราง, ดัชนีค้นหา และตั้งค่าความปลอดภัย RLS อัตโนมัติ

  1. ในหน้าแดชบอร์ดของ Supabase ให้มองแถบเมนูด้านซ้าย แล้วคลิกที่ไอคอน SQL Editor (สัญลักษณ์ >_)
  2. คลิกปุ่ม "+ New query" ด้านบน
  3. เปิดไฟล์ e:\my-appEval\supabase_schema.sql ในเครื่องของท่าน แล้วคัดลอก (Copy) โค้ดทั้งหมด นำมาวาง (Paste) ลงในช่องของ SQL Editor
  4. คลิกปุ่ม "Run" (หรือกดแป้น Ctrl + Enter) ที่มุมขวาล่าง
  5. เมื่อรันเสร็จ จะขึ้นข้อความแจ้งเตือนสีเขียวว่า Success. No rows returned
  6. คลิกไปที่เมนู Table Editor ด้านซ้าย จะพบตารางปรากฏขึ้นครบถ้วน ได้แก่:
    📁 departments 👨‍🏫 teachers ❓ survey_config 🎓 education_levels 🌾 majors 📊 responses 🔐 admin_users 📅 academic_periods
3

ขั้นตอนที่ 3: นำ API Keys มาเชื่อมต่อในไฟล์ .env

ผูกระบบหน้าบ้านเข้ากับฐานข้อมูล Supabase

  1. ใน Supabase คลิกที่ Project Settings (ไอคอนรูปฟันเฟือง ⚙️ ด้านล่างซ้ายสุด)
  2. เลือกเมนู API (หรือ Data API)
  3. ท่านจะเห็น 2 ค่าสำคัญ:
    • Project URL: เช่น https://abcdefghijklm.supabase.co
    • Project API Keys: ให้คัดลอกค่าในช่อง anon / public (ไม่ใช่ service_role)
  4. สร้างไฟล์ชื่อ .env ไว้ที่โฟลเดอร์หลัก e:\my-appEval\.env (สามารถคัดลอกโครงจากไฟล์ .env.example ได้)
  5. ใส่เนื้อหาดังนี้ (แทนที่ด้วยค่าจริงของท่าน):
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.your-anon-key-here

⚠️ ข้อควรระวัง: เมื่อสร้างหรือแก้ไขไฟล์ .env เสร็จแล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ Vite ด้วยการกด Ctrl+C ในเทอร์มินัล แล้วรัน npm run dev ใหม่อีกครั้งเพื่อให้ค่าคอนฟิกทำงาน

4

ขั้นตอนที่ 4: ทดสอบบนเครื่อง (Localhost) ให้ชัวร์ 100%

ตรวจสอบว่าการอ่านและบันทึกข้อมูลวิ่งไปยัง Supabase จริงหรือไม่

เปิดเบราว์เซอร์เข้าที่ http://localhost:5173 และทดสอบดังนี้:

✓
ทดสอบการล็อกอินแอดมิน:

เข้าหน้า /admin-login ล็อกอินด้วย admin / admin1234 ตรวจสอบว่าเข้าระบบได้ตามปกติ

✓
ทดสอบการส่งแบบประเมิน:

เปิดหน้า /evaluate?teacher_id=t1 ลองติ๊กคะแนน 1-5 กรอกข้อ 3.3 และ 3.4 แล้วกดส่งแบบประเมิน

✓
ตรวจสอบข้อมูลบน Supabase Cloud:

สลับหน้าจอไปที่ Supabase > Table Editor > เลือกตาราง responses จะต้องเห็นข้อมูลคำตอบที่เพิ่งส่งเข้าไปปรากฏอยู่บนตารางทันที!

5

ขั้นตอนที่ 5: นำโค้ดขึ้นระบบควบคุมเวอร์ชัน (GitHub)

เตรียม Repository สำหรับเชื่อมต่อกับ Cloud Hosting

  1. เปิดเว็บไซต์ https://github.com และสร้าง New repository (ตั้งชื่อ เช่น msat-evaluation-portal เลือกเป็น Private หรือ Public ตามสะดวก)
  2. เปิด PowerShell หรือ Terminal ในโฟลเดอร์ e:\my-appEval
  3. รันชุดคำสั่งด้านล่างนี้ตามลำดับ:
git init
git add .
git commit -m "feat: MSAT Teacher Evaluation Portal V12 with Supabase & Vocational Red"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/msat-evaluation-portal.git
git push -u origin main

*(หมายเหตุ: ไฟล์ .env จะถูกกันไว้ไม่ให้อัปขึ้น GitHub โดยอัตโนมัติตามไฟล์ .gitignore เพื่อความปลอดภัยของรหัสผ่านฐานข้อมูล)*

6

ขั้นตอนที่ 6: นำไประบบขึ้น Vercel (Online Cloud Hosting ฟรี)

ได้ URL จริงสำหรับเปิดใช้งานบนสมาร์ตโฟนและคอมพิวเตอร์ได้ทุกที่

  1. เปิดเว็บไซต์ https://vercel.com แล้วล็อกอินด้วยบัญชี GitHub
  2. คลิกปุ่ม "Add New..." แล้วเลือก "Project"
  3. จะเห็นรายชื่อ Repository จาก GitHub ให้กดปุ่ม "Import" ที่ชื่อโปรเจกต์ msat-evaluation-portal
  4. ในหน้าตั้งค่าก่อน Deploy ให้เปิดหัวข้อ "Environment Variables" แล้วเพิ่ม 2 ตัวแปร:
    Key: VITE_SUPABASE_URL | Value: (URL จาก Supabase)
    Key: VITE_SUPABASE_ANON_KEY | Value: (Anon Key จาก Supabase)
  5. คลิกปุ่ม "Deploy"
  6. รอประมาณ 1 นาที เมื่อขึ้นพลุเฉลิมฉลอง (Congratulations) ท่านจะได้ลิงก์เว็บไซต์จริง เช่น:
    🌐 ตัวอย่าง URL: https://msat-evaluation-portal.vercel.app

💡 ทำไมขั้นตอน "Supabase ➔ ทดสอบในเครื่อง ➔ GitHub ➔ Vercel" ถึงเป็นลำดับที่ถูกต้องที่สุด?

1. ลดข้อผิดพลาดตั้งแต่ต้นทาง: หากเราอัปขึ้น Vercel ก่อนโดยไม่มี Supabase เว็บจะยังไม่มีฐานข้อมูล เมื่อทดสอบจริงอาจพบปัญหาการเชื่อมต่อหรือการบล็อกสิทธิ์ RLS ซึ่งตรวจสอบในระบบ Cloud ได้ยากกว่าในเครื่อง
2. มั่นใจ 100% ก่อนเผยแพร่: เมื่อเราทดสอบส่งแบบประเมินบนเครื่อง localhost แล้วเห็นข้อมูลเข้า Supabase จริง หมายความว่าเมื่อ Deploy ขึ้น Vercel เว็บไซต์จะทำงานได้อย่างสมบูรณ์แบบตั้งแต่วินาทีแรก (Zero Downtime)
3. ระบบ Routing SPA: ระบบมีไฟล์ vercel.json เตรียมไว้ให้แล้ว ทำให้เมื่อกดรีเฟรชหน้าเว็บ หรือเปิดลิงก์ตรง เช่น /evaluate?teacher_id=t1 บน Vercel จะไม่พบข้อผิดพลาดหน้าเว็บ 404 แน่นอน 100%

⚡

วิธีป้องกันไม่ให้ Supabase หลับ (Keep Database Awake ตลอด 24/7)

นโยบาย Free Tier ของ Supabase จะ Pause ฐานข้อมูลหากไม่มีการใช้งานติดต่อกัน 7 วัน

หากไม่มีการเปิดใช้งานเว็บหรือส่งข้อมูลนานเกิน 7 วัน Supabase จะหยุดพักฐานข้อมูลชั่วคราว (ข้อมูลไม่หาย แต่ต้องกด Resume) เพื่อไม่ให้เกิดขึ้น เราสามารถตั้งค่าให้ระบบ "สะกิดฐานข้อมูลอัตโนมัติ" ได้ 2 วิธีฟรีดังนี้:

วิธีที่ 1 (⭐ แนะนำที่สุด): ใช้ GitHub Actions ที่สร้างไว้ให้แล้วในโปรเจกต์ อัตโนมัติ 100%

ในโปรเจกต์มีไฟล์ .github/workflows/keep_alive.yml เตรียมไว้ให้แล้ว เมื่อท่านอัปโค้ดขึ้น GitHub เพียงแค่ทำตามนี้:

  1. ในหน้า GitHub Repository ของท่าน คลิกไปที่แถบ Settings ด้านบน
  2. ที่เมนูด้านซ้าย เลือก Secrets and variables ➔ Actions
  3. กดปุ่ม "New repository secret" และเพิ่ม 2 ค่า:
    • Name: VITE_SUPABASE_URL | Secret: (URL ของ Supabase)
    • Name: VITE_SUPABASE_ANON_KEY | Secret: (Anon Key ของ Supabase)
  4. เสร็จสิ้น! GitHub Actions จะรันคำสั่ง ping สั้นๆ (ใช้เวลาเพียง 2 วินาที) ไปสะกิด Supabase ทุกๆ 3 วันโดยอัตโนมัติ ทำให้ฐานข้อมูลตื่นตัวตลอด 365 วันโดยไม่ต้องทำอะไรเพิ่มอีกเลย!
วิธีที่ 2: ใช้บริการฟรี Cron-Job.org หรือ UptimeRobot

หากไม่อยากตั้งค่าใน GitHub สามารถสมัครเว็บฟรี เช่น cron-job.org แล้วสร้าง Job ยิง HTTP GET ไปที่:

https://YOUR_PROJECT_ID.supabase.co/rest/v1/departments?select=id&limit=1

(ใส่ Header: apikey: YOUR_ANON_KEY และตั้งเวลาให้ยิงสัปดาห์ละ 1-2 ครั้ง)
